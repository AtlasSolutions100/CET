Earthwork — assign contours

Each row is a contour with the elevation read off the sheet. Set which surface it belongs to; fix any elevation the sheet reader got wrong. Volumes only compute where both surfaces overlap.
What this number is. A contour interpolation: the engine builds a triangulated surface through the contours you assign to each side and subtracts one from the other. It is not a measured earthwork quantity.
Where it applies. Each surface exists only inside a straight-sided envelope drawn around the contours you gave it (its convex hull), and the volume is integrated where the two envelopes overlap. That envelope cuts straight across every bay and notch in the real limit of disturbance and reaches out to the furthest contour, so the region is not the graded area and nothing on this panel can make it so.
What it does not have. The typical cross-section, the subgrade depth under each surface treatment, and a shrink/swell factor — none of the three is on the plans or in this calculation.
What that has cost, measured once. On the one sheet where a client estimate exists to check it against — Beaumont Barn Civil C3.0 (engine page index 2 = printed sheet 3) versus their Estimate #853 — cut, fill and import each read 2.3–2.5× high, and the region it integrated over was 317,632 SF against that estimator's own 224,058 SF of clear & grub (1.42×). One job is a sample, not a rate; treat every figure below as an order-of-magnitude check that a person still has to replace.

Pipe trench

Pick the pipe run, set its size and invert depths, and adjust the bedding rules to the spec. Depth interpolates start→end along each line; trench width = pipe OD + clearance each side, growing with depth per the rules.

Sheet callouts

Every leader on the sheet, paired with the note at its tail and the line it points at. Click a row to jump there. Callouts never count in the takeoff.

Whole job — marks by sheet

Every mark code in the document, per sheet and in total — the number you send a supplier. Counted from the sheets you have already run through Count; sheets not yet counted are listed so a partial document is never shown as a total. Where the schedule prints its own quantity, it sits beside ours so the two can be compared.

Across sheets — the same label twice

Every label that carries footage on more than one approved sheet, with what each sheet contributes. The engine cannot tell one run drawn twice from two real runs — you can. Untick a sheet to say “already counted”; that changes only the adjusted total below, never the sheet, the chains, or the Report PDF.

Count symbols

Every repeated shape found on the sheet. Hover a row to see every instance marked; name it and Add to put "× N EA" in the takeoff. The count comes from geometry, so it is checkable - the name is yours.

Structure — dig & backfill

Outline the building, then type the dig depth. Mass Excavation is the whole footprint dug to that depth (footprint × depth). Structure Excavation is the working trench around the outside of the foundation wall (wall length × depth × layback width), and Structure Backfill is that same trench filled back in after the wall is built (the same number). Slab Prep is the footprint area. All volumes in cubic yards (÷ 27).
