Earthwork — assign contours

Each row is a contour with the elevation read off the sheet. Set which surface it belongs to; fix any elevation the sheet reader got wrong. Volumes only compute where both surfaces overlap.

Pipe trench

Pick the pipe run, set its size and invert depths, and adjust the bedding rules to the spec. Depth interpolates start→end along each line; trench width = pipe OD + clearance each side, growing with depth per the rules.

Sheet callouts

Every leader on the sheet, paired with the note at its tail and the line it points at. Click a row to jump there. Callouts never count in the takeoff.

Count symbols

Every repeated shape found on the sheet. Hover a row to see every instance marked; name it and Add to put "× N EA" in the takeoff. The count comes from geometry, so it is checkable - the name is yours.
